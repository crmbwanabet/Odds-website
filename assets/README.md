# Website image assets

Drop the files below into these exact paths and they appear automatically — the
site already references them. Until a file is added it degrades gracefully:
missing logos fall back to a coloured monogram, and a missing hero photo shows a
claret gradient.

## Bookmaker logos — REQUIRED
Square, **transparent PNG**, ~128×128px (the book's icon/mark, not the wordmark):

| File | Bookmaker |
|------|-----------|
| `assets/logos/bwanabet.png` | BwanaBet |
| `assets/logos/sportybet.png` | SportyBet |
| `assets/logos/onexbet.png` | 1xBet |
| `assets/logos/betway.png` | Betway |
| `assets/logos/betpawa.png` | BetPawa |
| `assets/logos/bolabet.png` | BolaBet |

## Hero photo — RECOMMENDED
`assets/photos/hero-football.jpg` — landscape **16:9**, ~1600×900px.
Must be a **generic** football image (stadium, pitch, floodlights, ball or crowd
action) — the featured match changes every day, so it can't be team-specific.

## Optional
- `assets/favicon.png` — browser-tab icon, 64×64px.
- Extra hero photos if you'd like to rotate them later.
